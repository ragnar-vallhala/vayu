## Headline

**The roll and pitch inner rate loops do not track.** Commanded to hold level
(angle setpoint ≈ 0 the entire flight), the cascade's outer loop correctly
demands corrective body rates, but the inner rate loop answers with almost no
actuator output: roll/pitch `corr(rate_sp, rate_curr) ≈ 0.12`, and the
controller output never leaves ±0.13 of its ±1 range — even when pitch is 17.8°
off level. **Yaw, the one axis with a sane rate gain, tracks at corr 0.95.**

Root cause is a pure gain deficiency in the firmware defaults
(`include/variables.h`): roll/pitch rate `Kp = 0.0005` with `Kd = 0`, versus
yaw `Kp = 0.018` — a **36×** asymmetry. This is the **same** untuned-rate-loop
defect flagged on the 2026-06-17 bench rig, now reproduced in SITL.

The **vertical estimator is healthy** (fused-vs-baro residual RMS 0.25 m across
a violent ±60 m/s, 547 m manual climb/descent). There is **no altitude-hold
loop** in this build — throttle is manual passthrough — so the large altitude
excursion is the RC input, not a controller failure.
