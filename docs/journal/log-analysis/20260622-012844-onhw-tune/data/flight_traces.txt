1.0, the vehicle ALWAYS departs to the LEFT. Gain magnitude changes the violence of
the oscillation but never the DIRECTION. Direction is set by SIGN, not gain.
The yaw spin-sign was already proven backwards for this build (fixed via geometry).
=> Prime suspect: a roll and/or pitch mix/wiring SIGN inversion that the rig masked.
