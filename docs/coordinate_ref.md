# Coordinate System Reference

## Convention

- **+X**: FRONT
- **+Y**: RIGHT
- **+Z**: DOWN

All counter-clockwise (CCW) rotations are **POSITIVE**.
This is a **right-handed coordinate system** (standard aerospace FRD).

## Physical Motion (RHR)

| Motion                 | Expected Sign |
| :--------------------- | :------------ |
| Nose UP (Pitch)        | +pitch        |
| Right Wing DOWN (Roll) | +roll         |
| Turn RIGHT (Yaw)       | +yaw          |
